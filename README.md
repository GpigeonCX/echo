# echo

个人投资全景助手项目。

## 当前状态

项目已经可以本地运行和演示，但还没有完全覆盖原 Excel 的全部能力。

### 已完成

- Web 端基础页面
- API 基础服务
- 资产、计划、交易、组合总览接口
- 交易录入后自动汇总持仓
- 按最新价格快照计算总资产、现金仓、浮盈亏、当前权重
- 本地默认使用 SQLite 快速启动
- 生产可切换 MySQL

### 尚未完成

- 基金净值、港股价格、汇率自动抓取
- 历史峰值自动维护
- 最大回撤与回撤分档提醒
- 再平衡建议金额
- 进场计划执行进度的精确计算
- 邮件提醒任务
- Excel 历史数据导入

所以现在的系统状态是：

- 可以用于演示和继续开发
- 可以录交易、看持仓、看总览
- 还不能完全替代你现在 Excel 的全部自动化规则

## 目录结构

- `apps/web`: Nuxt 3 Web 前端
- `apps/api`: FastAPI 后端
- `database`: MySQL 初始化脚本
- `docs`: 需求、部署、运行说明

2. 完成峰值、回撤、再平衡规则

5. 做 Excel 数据迁移
